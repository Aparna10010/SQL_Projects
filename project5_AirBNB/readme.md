# 🏘️ Airbnb Housing Data Analysis using SQL

## 📌 Project Overview

This project uses SQL to analyze Airbnb listing data across neighborhoods, hosts, and room types. The goal is to extract meaningful insights such as pricing trends, host performance, listing availability, and review activity.

---

## 📁 Database & Table

* **Database Name:** `AIRBNB_HOUSING`
* **Table Name:** `AIRBNB_PROJECT`

---

## 🔍 Key Analyses Performed

### 📊 Listing & Pricing Insights

* Total listings per **neighborhood**
* Average price per **room type**
* Listings with price **above average**
* **Top 5 most expensive listings**
* Listings with **availability > 300 days**

### 🧑‍💼 Host Analytics

* Hosts with **more than 5 listings**
* Hosts with **listings in multiple neighborhoods**
* **Top hosts** based on total reviews
* Host with **most listings** and their average listing price
* **Total revenue** generated by each host

### 📈 Trend Analysis

* **Monthly average price** trends
* **Yearly price trends** per room type
* **Room types and median prices**

### 🧾 Review-Based Insights

* Neighborhoods with the **most reviews**
* Listings with **maximum reviews** per neighborhood
* Top hosts based on **monthly reviews**

### 📌 Advanced Queries

* **Price ranking** by neighborhood
* **Percentage of listings** by room type in each neighborhood
* Room types with **highest availability**
* **Top 5 expensive listings** in each neighborhood
* **Average price** by room type and neighborhood

---

## ✅ Sample Query – Listings by Room Type in Each Neighborhood

```sql
SELECT
    NEIGHBOURHOOD,
    ROOM_TYPE,
    COUNT(ID) * 100.0 / SUM(COUNT(ID)) OVER(PARTITION BY NEIGHBOURHOOD) AS PERCENTAGE
FROM
    AIRBNB_PROJECT
GROUP BY
    NEIGHBOURHOOD, ROOM_TYPE;
```
